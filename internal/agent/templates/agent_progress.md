Get detailed live progress for one background task by its ID (from AgentList, or from the response of the tool call that started it). Works for any kind of task, and reports what is meaningful for that kind: for a sub-agent, how long it's been running, how many tool calls it has made, and a snippet of its latest output; for a workflow, which phase it's in and the sub-agents each phase dispatched; for a scheduled task, how often it has fired and when it fires next. Use this to check on a specific task in flight instead of just seeing that it's "running".

This also answers for tasks that have already finished, reporting their outcome and final output from the stored transcript. A finished task stops appearing in AgentList, so disappearing from that list means it completed, not that it was lost -- a backgrounded task delivers its result into the dispatching conversation as a follow-up message. Check that result before assuming work needs redoing.
